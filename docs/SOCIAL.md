# 社交媒体发文的视觉标准

DuckEase Music 发在小红书这类平台的图文，统一按这套来做。参照样例是 [social/example-dual.html](social/example-dual.html)，即 2026-11-27 那篇「网易云负责推歌，Spotify 负责放」。新做一篇时，复制这个文件，改文字、换截图就行，样式不用动。

## 出图

```bash
docs/social/render.sh docs/social/example-dual.html build/social
```

脚本会做三件事：

1. 从 Simple Icons 下载网易云和 Spotify 的图标，放到 `docs/social/logos/`。
2. 用 `NM_PRESS_SCALE=2` 跑 README 截图的那个测试，按 2 倍分辨率把应用界面渲染进 `docs/social/shots/`。
3. 用无头 Chrome 把每一页截成 PNG，放到 `build/social/`。

`logos/` 和 `shots/` 都是生成出来的，不提交。发出去的图另存一份，不放进仓库。

## 画布

- 3:4 竖图。页面按 1242 × 1656 CSS 像素排版，用 `--force-device-scale-factor=2` 截图，输出 2484 × 3312。
- 页边距：上 96、左右 88、下 80。页脚贴在距底 56 的位置。
- 一篇 6 页左右，每页一个 `<section class="page" data-p="N">`，用 URL 的 `#N` 选择截哪一页。

## 字体与颜色

- 中文用苹方（PingFang SC），英文用 Century Gothic，本机从 Microsoft Excel 的字体目录里用 `@font-face` 加载。
- 底色 `#fbfaf7`（米白），卡片 `#ffffff`，分隔线 `#ececec`。
- 文字分三级：`#1d1d1f`（正文）、`#6e6e73`（说明）、`#a1a1a6`（页脚）。
- 强调色：网易云红 `#E60026`，Spotify 绿 `#1DB954`，DuckEase 红 `#E5484D`。品牌色只在提到对应服务时用，其余强调一律用 DuckEase 红。

## 版式元素

| 元素 | 规格 |
|---|---|
| 眉题 `.kicker` | 34px，600，说明色 |
| 封面大标题 `h1` | 104px，800，行高 1.16，字距 -2px；服务名用各自的品牌色 |
| 内页标题 `h2` | 72px，800，两行以内 |
| 说明段 `.note` | 36px，行高 1.55，说明色；关键词用 `<b>` 加黑 |
| 标签 `.tag` | 胶囊形，28px 粗体；底色是对应颜色的浅色（网易云 `#fdecef`、Spotify `#e8f8ee`、DuckEase `#fff0f1`） |
| 服务图标 `.logo` | 150px 圆角方块（圆角 40），品牌色底，白色图标，带投影；小号 84px |
| 卡片 `.pain` | 白底，圆角 30，细边框；左边是 64px 的编号方块（DuckEase 浅红底、红字） |
| 截图 `.shot` | 整宽，圆角 26，细边框，带柔和投影；用 2 倍渲染的图 |
| 页脚 `.foot` | 24px，页脚色；左边放免责或「界面截图为演示数据」，右边放页码 `N / 总数` |

## 结构

1. **封面**：一句话点明是给谁用的，大标题，两个服务的图标加双向箭头，底部一张 DuckEase 卡片（图标、名字、一句定位）。
2. **痛点**：四张编号卡片，每张先写痛点，下一行用「→」写项目怎么解决。
3. **功能页**（2 到 3 页）：标签加眉题、标题、一段说明、一张真实截图，必要时再配一个小流程或两张小卡片。
4. **最后一页「用之前先知道」**：把限制如实写出来，下面放 DuckEase 图标和「GitHub 搜 duckease-music」。

## 内容规矩

- 只写项目真正能做到的。数字、下载量、用户评价一律不编。
- 截图必须是应用界面的真实渲染，用演示数据，页脚注明「界面截图为演示数据」。
- 封面和最后一页都要写「非官方客户端，与网易云音乐、Spotify 无关」。服务图标只用来指代那个服务；图标的绘制采用 CC0 许可，商标仍归各自所有者。
- 限制必须讲清楚：不播放 Spotify 的音频；建 Spotify 开发者 app 需要 Premium；别人的歌单只能读前 100 首；只支持 Mac；非官方。
- 正文用作者本人的口吻，定稿前过一遍 sepia。不用营销腔，不堆砌 emoji。
